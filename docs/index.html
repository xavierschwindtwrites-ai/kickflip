Getting started

Up and running in two minutes

Download the installer, accept the (one-time) security warning, and start planning. No account, no email confirmation, no “welcome to our newsletter.”

Mac

  1. Download the .dmg file
  2. Open it and drag KickFlip to Applications
  3. Try to open KickFlip — macOS shows a security warning
  4. Open Terminal and run:
    xattr -cr /Applications/KickFlip.app
  5. Open KickFlip — it works normally from now on

One-time step, required because KickFlip isn’t yet signed with an Apple Developer certificate. You’ll never need it again.

Windows

  1. Download the .exe installer
  2. Run it — click “More info” then “Run anyway” if SmartScreen appears
  3. Launch KickFlip from the Start menu
  4. Future updates install automatically

The SmartScreen prompt appears because KickFlip isn’t yet code-signed. The source is fully open on GitHub if you’d like to verify.

FAQ

Questions you might be having

Honest answers to the things every indie author asks before downloading another desktop app.

Is it really free? Where’s the catch?
Really free. No subscription, no in-app purchases, no “pro tier” gating the useful features. KickFlip is MIT-licensed and the source is on GitHub — you can read every line yourself. The catch is there is no catch.
Where does my campaign data go?
Into a local SQLite file on your machine. KickFlip makes zero network requests for your data — no analytics, no telemetry, no cloud sync. And every campaign can be exported to a JSON file from the sidebar — perfect for backups or moving between machines.
Do I need to be a spreadsheet person to use this?
No. The whole point is to spare you that. Type your numbers into the relevant fields — pledge amounts, unit costs, shipping rates — and KickFlip handles the formulas. You’ll see the math, but you don’t have to write it.
What if I’m not launching on Kickstarter — or not launching a book?
KickFlip defaults to Kickstarter’s fee structure (5% platform + ~3% processing), but both rates are fully adjustable — so BackerKit, Indiegogo, or direct pre-orders model cleanly. And as of v0.3, nothing assumes you’re making a book: any product with a unit cost and shipping works.
Can I run more than one campaign?
Yes — as many as you want. Create, rename, duplicate, export, and delete campaigns from the sidebar. Useful for series, multiple editions, or A/B-ing reward structures before you commit.
Why isn’t the app code-signed?
Apple Developer and Microsoft signing certificates run a few hundred dollars a year, and KickFlip is free. The one-time security workaround takes about ten seconds. The source is open if you’d like to verify nothing untoward is happening.
Will my data survive an app update?
Yes. KickFlip stores campaigns in your user data folder, outside the app bundle. Updates replace the app, not your work — and on Windows, updates now install automatically.
I found a bug / want a feature. What now?
Open an issue on GitHub, or email me directly at xavier@hairyfeetwebsites.com. KickFlip is built and maintained by an indie author for indie authors, so your reports shape the roadmap directly — I read every one.
